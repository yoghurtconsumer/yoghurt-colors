CHROMATIC DESKTOP - PRIVATE WINDOWS X64 TEST BUILD

1. Extract the entire ZIP to a folder on your PC. Do not run it inside the ZIP.
2. Open that folder and double-click Chromatic.App.exe.
3. Keep the companions folder and every DLL beside the app. Do not send only EXE.

No SDK, Visual Studio, separate .NET installation or administrator rights needed.
Windows 10 build 19041+ or Windows 11, Intel/AMD x64 processor required.
This is a private development test build, not a signed public release.
Do not disable antivirus, anti-cheat or other Windows protections to run it.

Effects start OFF. Sliders initially edit a preview. Press Apply to change colors.
Restore and Exit request your captured original colors. Start with the desktop.
Use SDR: HDR/advanced color can block these controls. The app does not switch HDR.
No account, online service, firewall change, driver installer or LAN server needed.
Settings and local recovery/log data use your own Windows user profile, not the ZIP.

DESKTOP / BORDERLESS
Adjust Saturation on Display, then Apply. The matrix affects all monitors.
Some fullscreen presentation paths bypass desktop saturation.

EXPERIMENTAL NVIDIA VIBRANCE
For an NVIDIA-driven output: Settings -> experimental private NVIDIA DVC -> Save
and restart. Display -> Prepare NVIDIA vibrance -> select output -> Apply.
Keep Saturation at 100%; adjust Vibrance instead. Verify the result actually names
Magnification+NvidiaDvc. Software fallback does not establish fullscreen coverage.
NVIDIA driver DLLs are not included: only the already-installed System32 driver
interface is used. Driver/game compatibility has not been qualified.
