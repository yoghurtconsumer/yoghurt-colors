CHROMATIC DESKTOP - PRIVATE WINDOWS X64 TEST BUILD

1. Extract the entire ZIP to a folder on your PC. Do not run it inside the ZIP.
2. Open that folder and double-click Chromatic.App.exe.
3. Keep the companions folder and every DLL beside the app. Do not send only EXE.

Exit any older Chromatic copy before opening a build from a different folder.
If its window closed but Chromatic.App remains in Task Manager, end that old UI
and retry. This build fixes the shutdown hang that could block later launches.

No SDK, Visual Studio, separate .NET installation or administrator rights needed.
Windows 10 build 19041+ or Windows 11, Intel/AMD x64 processor required.
This is a private development test build, not a signed public release.
Do not disable antivirus, anti-cheat or other Windows protections to run it.

Effects start OFF. Sliders initially edit a preview. Press Apply to change colors.
Restore and Exit request your captured original colors. Start with the desktop.
Use SDR: HDR/advanced color can block these controls. The app does not switch HDR.
No account, online service, firewall change, driver installer or LAN server needed.
Settings and local recovery/log data use your own Windows user profile, not the ZIP.

DESKTOP / BORDERLESS
Adjust Saturation on Display, then Apply. The matrix affects all monitors.
Some fullscreen presentation paths bypass desktop saturation.

EXPERIMENTAL NVIDIA VIBRANCE
For an NVIDIA-driven output: Settings -> experimental private NVIDIA DVC -> Save
and restart. Display -> Prepare NVIDIA vibrance -> select output -> Apply.
Keep Saturation at 100%; adjust Vibrance instead. Verify the result actually names
Magnification+NvidiaDvc. Software fallback does not establish fullscreen coverage.
NVIDIA driver DLLs are not included: only the already-installed System32 driver
interface is used. Driver/game compatibility has not been qualified.

GLOBAL COLOUR DARKENING
Advanced global colour darkening changes matching colours throughout the desktop.
It cannot isolate Rust's holo or loot highlight. The old test shortcuts were
removed after whole-screen darkening feedback. If an old draft looks too dark,
use Restore, reset colour darkening / hue rotation, then explicitly Apply another
look. Existing accepted game presets are unchanged.

OPTIONAL RUST STARTING LOOK
Library -> Import JSON file -> presets/Rust-Vivid-Clarity.chromaticpreset.
Review, Confirm import, Preview, then explicitly Apply if desired. It adds richer
colour and a modest global lift. It cannot remove game shadows or reveal hidden
or fully black detail. Existing presets are preserved.

RESOLUTION CHECKPOINT
Refresh monitors, Load supported modes and Review mode plan are read-only.
Mode/HDR/scaling Apply, custom timing creation and monitor hardware writes remain
unavailable until the independent rollback transaction is implemented.

PLEASE REPORT
Windows version, GPU, whether desktop/borderless/fullscreen works, the exact Apply
result, and whether Restore/Exit returns your original colors. Report issues to
the person who sent this private build; nothing is uploaded automatically.
Logs: %LOCALAPPDATA%\ChromaticDesktop\logs and \sessions.
Library: save/preview named Color presets and share offline CD1 codes or
.chromaticpreset JSON. Review and confirm imports; nothing applies automatically.
Games saves bookmarks with manual Steam metadata discovery. Draft an exact-path
rule from a saved bookmark, enable it, opt into automatic profiles and Save
automation. Explicit Apply is still required to enable effects. The same panel
has optional hotkeys and basic whole-image hold lift, off by default. These use
OS foreground metadata and input callbacks in Chromatic; no game memory/input
modification. Settings has explicit per-user preset-link registration. Links
show an import diff and cannot apply automatically. Later pages remain unavailable.
